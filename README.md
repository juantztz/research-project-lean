# Lean Research Project

Mathematical proofs formalized in the [Lean 4](https://lean-lang.org/) theorem prover with [Mathlib](https://github.com/leanprover-community/mathlib4), documented as a Jupyter Book 2 site.

The full documentation (setup, dependencies, Google Drive sync, writing proofs, building the book) is in [`docs/docs/README.md`](docs/docs/README.md). Quick setup:

```bash
git clone git@github.com:juantztz/research-project-lean.git
cd research-project-lean
bash setup.sh
```
